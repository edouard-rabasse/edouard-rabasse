## Featured Projects

### [ring-attention](https://github.com/h1ppox99/ring-attention)
A from-scratch C++/CUDA implementation optimized for Stanford's Turing GPU cluster (`sm_75`).

### [SFUSD Choice Modeling](https://github.com/Stanford-MSandE-SFUSD/SFUSD-Choice-public)
Fits and evaluates Multinomial Logit (MNL) discrete-choice models on San Francisco Unified School District (SFUSD) school-choice data.

### [powerflow-gnn](https://github.com/h1ppox99/powerflow-gnn)
Graph neural networks for power systems, using GNNs to model and predict power flow in electrical grids.

### [VRP](https://github.com/edouard-rabasse/VRP)
Research internship project at CIRRELT (Montréal), using computer vision to predict planners' adjustments in Park-and-Loop routing problems.

## Hackathons

### [hackathon_MIT_MCP-OR](https://github.com/h1ppox99/hackathon_MIT_MCP-OR)
Collaborative project from the MIT Hackathon (Spring 2025), ranked **13th out of 100+ teams**.

We built an interactive application that computes optimal multimodal freight routes between cities based on user-defined priorities: travel time, cost, and CO₂ emissions.

### [Margo AI for Health Hackathon](https://github.com/edouard-rabasse/hackaton-margo)
Hackathon organized by Margo, Qubits Pharmaceuticals, and IBM, where we achieved **first place**.

The goal was to predict molecular toxicity from SMILES strings. We combined classical classification methods with deep learning.
